# Phoenix-Tasks
This repository contains solutions to the Python & OpenCV tasks, covering Python fundamentals (conditionals, loops, strings, lists, tuples, dictionaries, sets, recursion, OOP) and OpenCV-based image processing for drone vision applications.
## 📂 Repository Structure

| File | Question | Description |
|---|---|---|
| `Q1_drone_movement.py` | Q1 | Maps user input (1/2/3) to Roll/Pitch/Yaw drone movement |
| `Q2_weight_check.py` | Q2 | Computes total drone weight (grams→kg) and checks against 2kg limit |
| `Q3_drone_specs.py` | Q3 | Calculates max payload, prints variable types, checks camera fit, unit conversion |
| `Q4_telemetry_parser.py` | Q4 | Parses a pipe-separated telemetry string into structured fields |
| `Q5_flight_path.py` | Q5 | Analyses an altitude list — max altitude, average, climb rates, trimmed path |
| `Q6_waypoint_planner.py` | Q6 | Tuple-based waypoint mission planner with immutability demo |
| `Q7_fleet_health.py` | Q7 | Dictionary-based fleet health monitor (add/remove/update/query drones) |
| `Q8_airspace_checker.py` | Q8 | Set operations (intersection, difference, symmetric difference, subset) for airspace conflicts |
| `Q9_auto_rth.py` | Q9 | Auto Return-To-Home trigger logic + descent simulation loop |
| `Q10_data_structure_justification.txt` | Q10 | Essay justifying list/tuple/set choices for mission control data |
| `Q11_recursive_distance.py` | Q11 | Pure recursive functions for total path distance & longest leg |
| `Q12_OOP_pillars.txt` | Q12 | Explanation of the 4 pillars of OOP in Python |
| `Q13_coordinate_movement.py` | Q13 | Step-by-step coordinate movement simulator (horizontal/vertical) |
| `Q14_login_check.py` | Q14 | Lowercase-normalized user ID/password login check |
| `Q15_vowel_counter.py` | Q15 | Counts and lists vowels in a user-entered string |
| `Q16_ascii_uppercase.py` | Q16 | Converts lowercase → uppercase using only `ord()`/`chr()` |
| `Q17_landing_pad_detection.py` | Q17 | OpenCV: detects a white rectangular landing pad on a dark background |
| `Q18_red_object_tracking.py` | Q18 | OpenCV: HSV-based red object detection & circle tracking |
| `Q19_aerial_grid_view.py` | Q19 | OpenCV: 8x8 clickable grid overlay with cell-highlighting (mouse callback) |
| `Q20_color_detection_logic.txt` | Q20 | Description + text-flowchart of colour detection logic |
